# 经济学

经济学部分按 **微观 / 宏观** 两条主线组织。微观从个体决策出发，宏观从总量核算出发，两者通过
"加总" 与 "预期" 连接。公式统一用 LaTeX 书写，图形用文字描述其形状与移动方向。

## 写作约定

- 每一个模型都按「**假设 → 均衡 → 比较静态 → 现实偏离**」四段写；
- 公式中的变量第一次出现时必须写明含义与单位；
- 结论要区分"**模型结论**"与"**现实判断**"，不要把理想化假设下的结论直接当作政策建议。

> **提示**：正文中若出现美元符号 `$`，需转义为 `\$`，否则会被当作公式起始符。
