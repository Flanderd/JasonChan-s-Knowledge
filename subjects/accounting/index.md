# 会计学

会计学部分按 **基础会计 / 财务报表** 两条线组织。核心目标是把"每一笔业务"准确翻译成
"会计分录"，再汇总成报表，因此笔记里每一节都配有完整的分录示例。

## 写作约定

- 分录必须写成「**借：科目 金额 / 贷：科目 金额**」的形式，金额带单位 `元`；
- 涉及计算时列出算式，不直接给结果；
- 报表项目统一使用准则中的规范名称（如"应收账款""其他综合收益"），不用口语简称。

> **提示**：会计分录里的数字较长，建议用代码块对齐书写，避免 Markdown 表格挤压换行。
