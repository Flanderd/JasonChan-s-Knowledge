# 古诗词鉴赏方法

> **一句话概括**：鉴赏不是"感觉"，而是"举证"——每一个结论都要能在诗句里找到对应的依据。

## 为什么需要流程

考试中的失分大多不是"读不懂"，而是**想到了却写不出来**，或者**写了却没有指向得分点**。
把鉴赏拆成固定的四步，可以把主观感受转化为有文本依据的、可检查的表述。

## 四步读诗法

### 第一步：读懂字面

- 逐句翻译，把省略成分补出来（古诗词常见省略主语、介词、连词）；
- 标注**词类活用**与**特殊语序**，例如"春风又绿江南岸"的"绿"是形容词作动词；
- 圈出所有**意象词**（名词性的景物），这是后面分析的基础。

### 第二步：还原情境

回答四个问题，把诗放回它诞生的那一刻：

| 问题 | 关注点 |
| --- | --- |
| 何时 | 季节、时辰、节令（中秋、重阳常牵动思乡） |
| 何地 | 边塞、江南、客舍、旅途（空间距离暗示心理距离） |
| 何人 | 诗人身份与处境（贬谪、漫游、赴任、隐居） |
| 何事 | 送别、登高、访友、怀古、田园耕作 |

### 第三步：辨明手法

判断作者**用什么方法**把情意写出来，见下表。

### 第四步：提炼主旨

用一句完整的话概括："本诗通过描写______，运用______手法，表达了诗人______的情感。"
注意情感词要具体，避免"感慨万千""意味深长"这类空话。

## 常见表现手法速查

| 类别 | 手法 | 作用与答题话术 |
| --- | --- | --- |
| 抒情方式 | 直抒胸臆 | 情感表达直白强烈，感染力强 |
| 抒情方式 | 借景抒情 / 情景交融 | 将情感寄寓于景物，含蓄蕴藉，耐人寻味 |
| 抒情方式 | 托物言志 | 借物的特征象征品格志向，使抽象品格具体可感 |
| 描写角度 | 动静结合 | 以动衬静或以静衬动，使画面富有生气 |
| 描写角度 | 虚实结合 | 实写眼前之景，虚写想象、回忆之景，拓展意境 |
| 描写角度 | 白描 | 不加烘托，寥寥数笔勾勒出鲜明形象 |
| 修辞手法 | 比喻 / 拟人 | 使描写对象生动形象，便于读者体会情感 |
| 修辞手法 | 用典 | 借古人古事含蓄表达心志，言简义丰 |
| 结构技巧 | 卒章显志 | 在结尾点明主旨，收束有力 |
| 结构技巧 | 以景结情 | 结尾不直说，只写景，言有尽而意无穷 |

## 示例：《天净沙·秋思》

> 枯藤老树昏鸦，小桥流水人家，古道西风瘦马。夕阳西下，断肠人在天涯。

**第一步（字面）**：意象密集堆叠——枯藤、老树、昏鸦、小桥、流水、人家、古道、西风、瘦马，
前三句共 18 字却列出 9 个名词性意象，中间几乎不用动词。

**第二步（情境）**：时间是黄昏（"夕阳西下""昏鸦"），地点在异乡古道，人物是漂泊的旅人，
事件是赶路途中触景生情。

**第三步（手法）**：

- **白描**：不加修饰地罗列意象，画面感极强；
- **对比**："小桥流水人家"的温馨安宁，反衬出游子的孤苦无依，属**以乐景写哀情**；
- **情景交融**：前四句全是景，最后一句"断肠人在天涯"点情，前面所有景物都染上愁绪。

**第四步（主旨）**：作品通过描绘秋日黄昏旅途的萧瑟景象，运用白描与以乐景写哀情的手法，
抒发了漂泊天涯的旅人浓重的羁旅之愁与思乡之苦。

## 答题模板

### 炼字题

> 某字用得好，好在哪里？

1. 释义：该字在句中的含义是______；
2. 描景：它写出了______（景物特征/动态过程）；
3. 手法：运用了______（活用/拟人/通感）；
4. 传情：烘托了______的氛围，表达了诗人______的情感。

### 意境题

> 这首诗营造了怎样的意境？

1. 概括图景：描绘了一幅______的（季节/时间/地点）图景；
2. 概括氛围：用两个双音节词概括，如"清幽静谧""雄浑苍凉""萧瑟凄清"；
3. 关联情感：寄托了诗人______的心境。

## 常见误区

| 误区 | 修正 |
| --- | --- |
| 只写情感，不引诗句 | 情感前必须有文本依据，先引后析 |
| 手法堆砌，不加辨析 | 只写最有把握的两三点，每点都要说清作用 |
| 把"意境"写成"意象" | 意象是单个物象，意境是物象整体营造的氛围 |
| 情感词笼统 | 把"伤感"具体化为"羁旅之愁""亡国之痛""壮志难酬" |

## 练习

1. 用四步法分析王维《山居秋暝》的颔联"明月松间照，清泉石上流"；
2. 比较杜甫《登高》与李白《秋浦歌》中"秋"的意象所承载的情感差异；
3. 找一首用典的作品，说明典故原意与诗中用意的关系。
