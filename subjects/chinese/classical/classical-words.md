# 文言实词与虚词

> **一句话概括**：文言阅读的障碍 80% 集中在"熟词生义"和"虚词辨义"上，两者都需要按义项记忆而非按字记忆。

## 一、实词记忆法

### 三条原则

1. **以本义带引申义**：先记住本义，再顺着"由具体到抽象"的链条推引申义；
2. **一个义项配一个原句**：脱离句子的义项记不住，必须绑定语境；
3. **古今异义单独标注**：双音节词在文言中常是两个单音节词，如"妻子"指"妻子和儿女"。

### 高频实词义项卡

| 词 | 本义 | 常见引申义 | 例句 |
| --- | --- | --- | --- |
| 兵 | 兵器 | 士兵、军队、战争、战略 | 「收天下之**兵**，聚之咸阳」——兵器 |
| 病 | 重病 | 担心、困苦、指责 | 「君子**病**无能焉」——担心 |
| 乘 | 登、升 | 驾车、趁机、量词（四马一车） | 「**乘**彼垝垣」——登上 |
| 从 | 跟随 | 顺从、参与、由、堂房亲属 | 「**从**此道至吾军」——由、自 |
| 道 | 道路 | 方法、道义、说、取道 | 「师者，所以传**道**受业解惑也」——道理 |
| 顾 | 回头看 | 看望、考虑、但、反而 | 「**顾**不如蜀鄙之僧哉」——反而 |
| 举 | 举起 | 推荐、发动、全、攻克 | 「**举**孝廉不行」——被推荐 |
| 绝 | 断绝 | 横渡、极、停止、与世隔绝 | 「非能水也，而**绝**江河」——横渡 |
| 间 | 缝隙 | 参与、秘密地、隔阂、间或 | 「又何**间**焉」——参与 |
| 信 | 言语真实 | 信用、确实、使者、随意 | 「**信**可乐也」——确实 |

### 词类活用辨识

| 类型 | 辨识方法 | 例句 |
| --- | --- | --- |
| 名词作动词 | 名词前有副词或后带宾语 | 「左右欲**刃**相如」——用刀杀 |
| 使动用法 | 动词/形容词后接宾语，意为"使宾语怎样" | 「项伯杀人，臣**活**之」——使他活 |
| 意动用法 | 形容词/名词后接宾语，意为"认为宾语怎样" | 「吾妻之**美**我者」——认为我美 |
| 名词作状语 | 名词直接修饰动词，表比喻、工具、处所 | 「**犬**坐于前」——像狗一样坐着 |

## 二、18 个常见虚词

| 虚词 | 主要用法 | 例句 |
| --- | --- | --- |
| 而 | 并列、承接、转折、修饰、假设 | 「蟹六跪**而**二螯」——并列 |
| 何 | 疑问代词、副词（多么） | 「**何**陋之有」——什么 |
| 乎 | 疑问语气、介词（相当于"于"）、形容词词尾 | 「其闻道也固先**乎**吾」——比 |
| 乃 | 于是、才、竟、是、你的 | 「**乃**不知有汉」——竟然 |
| 其 | 代词、副词（大概/难道）、连词（如果） | 「**其**孰能讥之乎」——难道 |
| 且 | 而且、况且、将要、暂且 | 「**且**焉置土石」——况且 |
| 若 | 像、如果、你（们）的 | 「**若**属皆且为所虏」——你们这些人 |
| 所 | 与动词组成"所"字结构，表"……的事物" | 「道之**所**存，师之所存也」 |
| 为 | 做、作为、被、因为、替 | 「身死国灭，**为**天下笑」——被 |
| 焉 | 兼词（于之）、代词、语气词、形容词词尾 | 「积土成山，风雨兴**焉**」——在那里 |
| 也 | 判断、陈述、疑问、停顿语气 | 「师者，所以传道受业解惑**也**」 |
| 以 | 用、凭、因为、来、以致、认为 | 「不**以**物喜，不以己悲」——因为 |
| 因 | 依靠、趁着、通过、于是 | 「**因**宾客至蔺相如门谢罪」——通过 |
| 于 | 在、从、到、向、比、被 | 「青，取之**于**蓝」——从 |
| 与 | 和、给、结交、赞许、通"欤" | 「**与**嬴而不助五国也」——结交 |
| 则 | 就、却、就是、那么 | 「位卑**则**足羞」——就 |
| 者 | 代词（……的人/事）、判断句标志、提顿 | 「古之学**者**必有师」 |
| 之 | 代词、助词（的 / 取消句子独立性 / 提宾 / 定语后置标志）、动词（往） | 「师道**之**不传也久矣」——取消独立性 |

## 三、四类特殊句式

| 句式 | 标志 | 例句与翻译 |
| --- | --- | --- |
| 判断句 | ……者……也、乃、则、为、即 | 「陈胜者，阳城人也」——陈胜是阳城人 |
| 被动句 | 于、为、为……所、见、被 | 「吾属今为之虏矣」——我们这些人要被他俘虏了 |
| 宾语前置 | 否定句代词宾语前置；疑问代词宾语前置；"之""是"提宾 | 「古之人不余欺也」——古代的人没有欺骗我 |
| 定语后置 | 中心词 + 之 + 形容词；中心词 + 数量词 | 「蚓无爪牙之利」——蚯蚓没有锋利的爪牙 |

### 状语后置（介词结构后置）

"于/以 + 宾语"常放在动词之后，翻译时要提到动词前面：
「青，取之于蓝，而青于蓝」→ 靛青，是从蓝草里提取出来的，可是比蓝草更蓝。

## 四、翻译六字诀

**留、删、补、换、调、贯**：

1. **留**：国名、地名、人名、官名、年号等专有名词保留；
2. **删**：无实在意义的虚词（发语词、凑足音节的助词）直接删去；
3. **补**：补出省略的主语、谓语、宾语、介词；
4. **换**：古今异义词换成现代汉语，单音节词换成双音节词；
5. **调**：调整特殊句式的语序；
6. **贯**：根据上下文把语气、情感贯通成通顺的现代汉语。

## 常见误区

- 见到"所以"就翻译为因果连词：文言中"所以"常表"用来……的（方法）"；
- 把"无论"当作连词：文言中是"不要说"；
- 以为"之"取消句子独立性后可以译出：它没有实在意义，不译。
