# 议论文结构

> **一句话概括**：议论文的竞争力不在辞藻，而在"论点是否站得住、论证是否推进了"。

## 一、审题立意

### 四步审题

1. **辨题型**：材料作文、命题作文、话题作文、漫画作文；
2. **抓关键**：圈出材料中的高频词、转折词（"然而""但"）与价值判断词；
3. **定范围**：材料要求谈"个人成长"还是"社会现象"，不要越界；
4. **找角度**：从材料中至少列出三个可选角度，再挑最有话说的那个。

### 立意的三个标准

- **准**：不偏题，与材料核心词保持一致；
- **深**：不停留在"要努力"这类常识层面，追问"为什么""怎么办"；
- **新**：在常规观点基础上增加一个限定条件，例如把"坚持"具体到"有方向的坚持"。

中心论点必须是一句**完整的陈述句**，包含判断词（是、需要、决定、意味着）。

## 二、三种常用结构

### 结构一：并列式（是什么—为什么—怎么办）

```
引论：概述材料，提出中心论点
本论：
  分论点①：是什么（界定概念）
  分论点②：为什么（分析原因与意义）
  分论点③：怎么办（提出路径）
结论：升华主旨，回应现实
```

### 结构二：层进式（现象—危害—根源—对策）

适合评析社会现象类材料，四个环节逐层深入，逻辑推进感最强。

### 结构三：正反对照式（正面论证 + 反面论证 + 辨析）

先正面立论，再设想反面情形，最后用"或曰……然而……"进行让步反驳，
使论证更严密，不容易被驳倒。

## 三、段落内部展开

推荐使用「**论点句 — 阐释句 — 事例句 — 分析句 — 结论句**」五步法：

- **论点句**：放在段首，一句话说清本段主张；
- **阐释句**：解释关键词的含义，或说明为什么这样说；
- **事例句**：概括论据，控制在 60 字以内，只保留与论点相关的部分；
- **分析句**：这是最关键的一步——说明"这个事例为什么能证明论点"，
  常用方法：假设分析（"假如没有……就不会……"）、因果分析、对比分析；
- **结论句**：回扣分论点，最好能呼应中心论点。

> **提醒**：缺少"分析句"是议论文最常见的失分点。只摆事例不作分析，
> 事例与论点之间就缺少逻辑连接。

## 四、论据的选取

### 三条标准

1. **真实准确**：人物、时间、数字不能出错，拿不准就改用熟悉的素材；
2. **贴切对口**：素材的核心特质必须与论点一致，不贴切的宁可不用；
3. **新颖适度**：避开被写烂的例子，或在使用角度上出新。

### 素材分类储备

| 类别 | 建议储备数量 | 示例方向 |
| --- | --- | --- |
| 古代人物 | 3—5 个 | 苏轼、司马迁、王阳明 |
| 近现代人物 | 3—5 个 | 钱学森、袁隆平、屠呦呦 |
| 当代热点 | 2—3 组 | 科技攻关、乡村振兴、文化传承 |
| 名言警句 | 10 句左右 | 按"坚持""创新""担当"等主题分类 |

一个素材要能从**不同角度**解读，例如袁隆平既可用于"梦想"，也可用于"脚踏实地""科学精神"。

## 五、语言升格

1. **化抽象为具象**：把"坚持"写成"把一件事重复一万次而不改其志"；
2. **善用短句与整句**：议论段中适当插入整散结合的句式，增强节奏感；
3. **准确使用关联词**：让逻辑关系显性化（"并非……而是……""与其……不如……"）；
4. **控制修辞密度**：议论文以说理为主，修辞服务于表达，不必堆砌。

## 六、开头与结尾

### 开头三法

- **引材点睛**：简述材料后直接点明论点，最稳妥；
- **设问引入**：以问题开头，引发思考后作答；
- **场景切入**：用简短的画面描写引入，再过渡到议论。

### 结尾三法

- **回应式**：回扣开头与材料，形成闭环；
- **升华式**：从个人推及社会、时代、文明；
- **呼告式**：发出号召，增强感染力，但要避免空洞口号。

## 常见误区

| 误区 | 修正 |
| --- | --- |
| 论点散在全文，没有一句话概括 | 中心论点必须独立成句，置于醒目位置 |
| 三个分论点互相交叉 | 分论点之间应并列或层进，不重叠 |
| 事例写成了记叙文 | 议论文中事例只需概括，重心在分析 |
| 结尾重抄开头 | 结尾应升华而非重复 |
