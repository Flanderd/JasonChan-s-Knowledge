# 矩阵与行列式

> **一句话概括**：行列式是一个数，用来判断矩阵是否"塌缩"；矩阵是一个变换，秩衡量它保留了多少维度。

## 一、矩阵运算

### 基本运算

- 加减：同型矩阵对应元素相加减；
- 数乘：$kA$ 表示每个元素都乘 $k$；
- 乘法：$C = AB$ 中 $c_{ij} = \sum\limits_{k=1}^{n} a_{ik}b_{kj}$，要求 $A$ 的列数等于 $B$ 的行数；
- 转置：$(AB)^T = B^T A^T$（注意顺序反转）。

### 与数运算的区别

| 性质 | 数的运算 | 矩阵运算 |
| --- | --- | --- |
| 交换律 | $ab = ba$ | 一般 $AB \neq BA$ |
| 消去律 | $ab = ac \Rightarrow b = c$ | 不成立，除非 $A$ 可逆 |
| 零乘积 | $ab = 0 \Rightarrow a=0$ 或 $b=0$ | 不成立，可出现非零的零因子 |

## 二、行列式

### 定义与性质

二阶行列式 $\begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc$。
$n$ 阶行列式按行展开：$|A| = \sum\limits_{j=1}^{n} a_{ij}A_{ij}$，其中 $A_{ij}$ 为代数余子式。

常用性质：

1. 换行变号，两行相同则行列式为 $0$；
2. 某行乘 $k$，行列式乘 $k$，即 $|kA| = k^n|A|$；
3. 将一行的倍数加到另一行，行列式不变（**这是手算的关键技巧**）；
4. $|AB| = |A|\cdot|B|$，$|A^T| = |A|$，$|A^{-1}| = \dfrac{1}{|A|}$。

### 计算策略

先用性质 3 化为上三角（或阶梯形），此时行列式等于主对角线元素之积，
比直接按行展开快得多。

## 三、可逆矩阵

### 等价条件

对 $n$ 阶方阵 $A$，以下命题等价：

1. $|A| \neq 0$；
2. $A$ 可逆（非奇异），存在 $A^{-1}$ 使 $AA^{-1} = A^{-1}A = I$；
3. $r(A) = n$（满秩）；
4. $A$ 的行（列）向量组线性无关；
5. 齐次方程组 $Ax = 0$ 只有零解。

### 求逆方法

- **伴随矩阵法**：$A^{-1} = \dfrac{1}{|A|}A^*$，其中 $A^*$ 为伴随矩阵（代数余子式矩阵的转置）；
- **初等行变换法**：对增广矩阵 $[A \mid I]$ 施行行变换，化为 $[I \mid A^{-1}]$，
  三阶以上矩阵用这个方法更省事。

## 四、矩阵的秩

秩 $r(A)$ 定义为最高阶非零子式的阶数，也等于行（列）向量组的极大无关组所含向量个数。
初等变换**不改变**矩阵的秩，因此可用行变换化为阶梯形后数非零行的行数。

常用不等式：

$$
r(A + B) \le r(A) + r(B), \qquad
r(AB) \le \min\{r(A),\ r(B)\}
$$

## 五、与线性方程组的连接

对方程组 $Ax = b$（$A$ 为 $m \times n$ 矩阵，$r = r(A)$）：

| 条件 | 解的情况 |
| --- | --- |
| $r(A) < r(A \mid b)$ | 无解 |
| $r(A) = r(A \mid b) = n$ | 有唯一解 |
| $r(A) = r(A \mid b) < n$ | 有无穷多解，自由变量个数为 $n - r$ |

对齐次方程组 $Ax = 0$：当 $r < n$ 时有非零解，基础解系含 $n - r$ 个向量。

## 常见误区

- 把 $(A+B)^2$ 展开为 $A^2 + 2AB + B^2$：缺少交换律时不成立；
- 认为 $|A + B| = |A| + |B|$：行列式对加法不具线性；
- 混淆 $|kA|$ 与 $k|A|$：前者是 $k^n|A|$。
